Owner notes / Adding data

Add a session.

  1. Open records/athletics/swimming/Swimming_Log.txt in the pandas_projects folder. It is plain text (.txt). The CSV and JSON files on this page are exports made from it at every build; editing them changes nothing.
  2. Add one line per session, oldest first: (10/6/2026) - 2000m - 5x400 of Fly-Back_Breast-Free. Sets × set distance must equal the total, and the stroke order is separated by - or _.
  3. Rebuild from pandas_projects with python -B -m site_content.build --also-local. Any line the build cannot read stops it with the line number.
  4. Publish by committing and pushing the liammspandasprojects repository.

The latest entry, as written:

(10/04/2026) - 2400m - 6x400 of Fly-Back_Breast-Free

An older copy at LiamMs_PandasProjects/Gaming-and-Performance-Log/Athletics/ is checked too: if it differs from the file above, the build stops instead of skipping the edit.
