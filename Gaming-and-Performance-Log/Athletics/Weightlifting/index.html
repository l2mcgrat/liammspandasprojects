The evidence desk

How these numbers are made.

  • Source: records/athletics/weightlifting/Weightlifting_Log.txt; dropsets are excluded in the log itself.
  • Exercise names are shown with spelling fixed (for example Dumbell → Dumbbell); the raw names stay in the downloads. Differently named lifts are never merged.
  • Assisted lifts record the machine's assistance, so lower numbers mean more bodyweight lifted.

Owner notes / Adding data

Add a session.

  1. Open records/athletics/weightlifting/Weightlifting_Log.txt in the pandas_projects folder. It is plain text (.txt). The CSV and JSON files on this page are exports made from it at every build; editing them changes nothing.
  2. Start each day with a line like 10/6/2026 - Chest & Abs; the first word is the split (Chest, Back, Delts or Shoulders). Below it, one line per exercise: Exercise Name; 12x95lbs, 10x115lbs, 8x125lbs, sets as reps x pounds. Write 0lbs for bodyweight sets and keep Assisted in the name for assisted machines. A ; or : after the name both work.
  3. Rebuild from pandas_projects with python -B -m site_content.build --also-local. Any line the build cannot read stops it with the line number.
  4. Publish by committing and pushing the liammspandasprojects repository.
