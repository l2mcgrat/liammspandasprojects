  1. Canonical repo file: records/athletics/running/Interval_Data.txt (synced with Google Drive Logs/ via python -B -m site_content.log_sync). The CSV and JSON files on this page are exports made from it at every build.
  2. Add a block per session: a line like I1 - (10/6/2026) - 4 Intervals, then one m:ss or m:ss.s time per line, then optionally Avg: m:ss. The interval count must match the times listed; the written average is kept beside the computed mean.
  3. Tempo runs go in records/athletics/running/Tempo_Run_Log.txt: a (10/12/2026) line, a Tempo Run - 5.8km (Route Name) line, the total time like 33:23.81, then the pace line like 5:45.5 min/km - 2.89m/s.
  4. To sync all 6 logs from your Google Drive Logs/ folder or linked Google Docs and rebuild, run python -B -m site_content.log_sync && python -B -m site_content.build --also-local. Deterministic regex rules fix dates, units, and dashes at 0 token cost; LLM repair is only called if a line still fails validation.
  5. Publish by committing and pushing the liammspandasprojects repository.
