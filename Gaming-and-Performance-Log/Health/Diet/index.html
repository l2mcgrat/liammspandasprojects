The evidence desk

How these numbers are made.

  • Source: records/health/diet/Diet_and_Calorie_Tracking.txt; any unreadable line stops the build.
  • Deficit = written expenditure − written consumption. Headlines and net lines that disagree with that arithmetic are flagged, never corrected.
  • BMR is the owner's setting of 2,050 kcal for October; expenditure notes in parentheses (walks, cold, dancing) are kept with the day.
  • Macro sums add the per-meal triples; meals without a triple contribute nothing rather than a guess.

Owner notes / Adding data

Add a session.

  1. Open records/health/diet/Diet_and_Calorie_Tracking.txt in the pandas_projects folder. It is plain text (.txt). The CSV and JSON files on this page are exports made from it at every build; editing them changes nothing.
  2. Add a date line like 10/19/2026, meal lines like Lunch - 76/29/13g Yam Bowl (macros are carbs/fat/protein grams), then Total Expenditure - 3400cals, Total Consumption - 2800cals - 300/100/150g and Net Expenditure - 600cals loss.
  3. Rebuild from pandas_projects with python -B -m site_content.build --also-local. Any line the build cannot read stops it with the line number.
  4. Publish by committing and pushing the liammspandasprojects repository.
