\section{Executive Summary \& Core Paradox}
Between March 2023 and October 2026, the unit price of frontier-equivalent large language model (LLM) inference collapsed by \textbf{10.3$\times$ to 200$\times$} (from \$36.00 per million blended tokens for original GPT-4 to \$3.50/1M for Gemini 4 Argon High Thinking, \$0.48/1M for DeepSeek-R1, and \$0.18/1M for Gemini 3.8 Flash), while composite reasoning accuracy on MMLU-Pro and GPQA Diamond rose by $+11.8$ to $+21.2$ percentage points.

Simultaneously, the upfront capital expenditure required to pre-train a frontier base model rose from \$78M to \$130M--\$1B+ per cluster generation. This study formalizes the two-part tariff of modern AI infrastructure:
\begin{enumerate}
  \item \textbf{Marginal Inference Deflation ($\approx 68\%$--$85\%$/year):} Driven by Sparse Mixture-of-Experts (MoE) routing, Multi-head Latent Attention (MLA) KV-cache compression, FP8/INT4 quantization, and custom ASICs (TPU v6e / Blackwell B200).
  \item \textbf{Jevons Paradox via Test-Time Reasoning:} As unit token prices fall by two orders of magnitude, test-time compute scaling (chain-of-thought search trees in Gemini 4 Argon, o3, and R1) multiplies token volume per complex query by $5\times$--$15\times$, expanding aggregate enterprise spend even as per-token prices plummet.
\end{enumerate}

\section{First-Principles Theory: Chinchilla Scaling, Memory Bandwidth \& KV-Cache Mechanics}

\subsection{Pre-Training Compute \& Chinchilla Optimality}
For a dense transformer with $N$ active parameters trained on $D$ tokens, total training floating-point operations scale as:
\begin{equation}
  C_{\text{train}} \approx 6 N D, \qquad L(N, D) = E_0 + \frac{A}{N^{\alpha}} + \frac{B}{D^{\beta}}.
  \label{eq:chinchilla}
\end{equation}
In a Sparse Mixture-of-Experts (MoE) architecture with $N_{\text{total}}$ total parameters and $N_{\text{active}} \leq N_{\text{total}}$ routed per token (e.g.\ $N_{\text{active}} = 37\text{B}$ out of $N_{\text{total}} = 671\text{B}$), forward-pass FLOPs per token drop from $2 N_{\text{total}}$ to $2 N_{\text{active}}$.

\subsection{The Arithmetic Intensity \& HBM3e Memory Wall}
Autoregressive token decoding generates one token per forward pass per sequence. At batch size $B_{\text{seq}}$, the operational intensity (FLOPs per byte transferred from High-Bandwidth Memory) is bounded by weight and Key-Value (KV) cache reads:
\begin{equation}
  T_{\text{step}} = \max\left( \frac{2 B_{\text{seq}} N_{\text{active}}}{\text{FLOP/s}_{\text{peak}}}, \; \frac{b_w N_{\text{active}} + 2 b_{kv} B_{\text{seq}} L_{\text{ctx}} n_{\text{layers}} d_{kv}}{\text{BW}_{\text{HBM}}} \right),
  \label{eq:roofline}
\end{equation}
where $b_w$ and $b_{kv}$ are bytes per weight and KV-cache element, and $L_{\text{ctx}}$ is context length. Multi-head Latent Attention (MLA) projects keys and values into a low-rank latent vector $d_c \leq n_{\text{heads}} d_h$, reducing KV-cache memory traffic by $75\%$--$88\%$.

\section{Enterprise Cascade Routing \& Societal Implications}
Let an enterprise workload process $V = 10^8$ tokens/month across routine extraction ($1 - \theta = 0.85$) and deep mathematical or architectural reasoning ($\theta = 0.15$). Under a two-tier cascade router pairing Gemini 3.8 Flash ($p_{\text{fast}} = \$0.18/\text{1M}$) with Gemini 4 Argon High Thinking ($p_{\text{deep}} = \$3.50/\text{1M}$):
\begin{equation}
  p_{\text{cascade}} = (1 - \theta) p_{\text{fast}} + \theta p_{\text{deep}} = 0.85(0.18) + 0.15(3.50) = \$0.678/\text{1M tokens},
  \label{eq:cascade}
\end{equation}
yielding an \textbf{80.6\% reduction in total inference expenditure} relative to routing $100\%$ of traffic through a frontier reasoning model, while preserving frontier accuracy on hard tail queries.
